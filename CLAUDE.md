# Internship Radar

This folder is a personal internship radar. When the user asks to set it up, run it, change it, or
add a source or alert, follow SKILL.md in this folder. Keep the user's files here: my-radar.json
(profile), radar.env (passwords and tokens: never print it, never commit it), radar-state.json,
radar-latest.md and my-tracker.csv. Run the tests with `python3 -m unittest discover -s tests`.
